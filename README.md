# L2BGreen: Gaia conversational tutor and learning platform

Gaia is a multi-agent conversational tutor that guides learners through realistic green
entrepreneurship cases. It gives hints and follow-up questions before answers, and gives
feedback on the learner's arguments. It was developed by Enchatted in the Erasmus+ project
L2BGreen (Learning to Be Green), grant agreement 101139849, 1 April 2024 to 31 March 2027.

## Status

The source code will be published in this repository at the end of the project (March 2027),
together with deployment documentation (project deliverable D4.4).

Until then, Gaia is open to use with the project's standard cases on the L2BGreen learning
platform: https://lms.l2bgreen.com

## What the repository will contain

- **Gaia interaction engine**: the multi-agent tutor (case presentation, knowledge
  scaffolding, application coaching, argumentation feedback) with a moderation layer.
- **Educator and administration platform**: case activities, users and teams, learner
  analytics and conversation export.
- **LMS integration**: connection to Moodle or any compliant LMS through LTI 1.3.
- **Multilingual support**: English, German, Dutch, Estonian, Greek and Slovenian.
- **Deployment documentation**: setup, configuration of your own language-model access,
  LMS integration and case import.
